## FolderView Plus 2026.08.10.01

### Recoverable startup diagnostics

- Reliability: Replace generic bootstrap failures with a shared startup-incident model across Settings, Docker, VM, Dashboard, and the folder editor.
- Reliability: Add a bounded **Try loading again** action that resumes the Settings loader from the failed module, cache-busts only that retry, and keeps reload available as the safe fallback.
- Diagnostics: Record module stage, outcome, duration, asset version, retry state, resource timing, last completed step, and recovery history without exposing private runtime values.
- Diagnostics: Preserve the latest startup incident for 24 hours in browser-session storage so a sanitized support bundle can include the failure after navigation or successful recovery.
- Privacy: Make copied support codes and downloadable startup reports sanitized by default, reducing URLs to routes and masking private hosts, addresses, and filesystem paths.
- Accessibility: Add plain-language failure summaries, visible reference codes, keyboard focus, live-region semantics, focus indicators, reduced-motion handling, and translated recovery actions.
- Localization: Add the startup recovery vocabulary to all 27 supported locales and advance the complete 2,060-message catalog to revision `2026.08.10.1`.
- Performance: Stage Settings workspace modules after an idle or interaction opportunity and apply a 12-second per-module timeout so stalled assets fail predictably instead of leaving a blank page.
- Maintenance: Document the incident lifecycle, module-loader telemetry, support workflow, and recovery behavior; refresh CSP readiness metadata and deterministic browser contracts.
- Regression guard: Add fault-injection coverage for failed and stalled assets, one-shot recovery, CSP classification, sanitized persistence, support-bundle redaction, Settings failure presentation, and cross-surface bootstrap wiring.
