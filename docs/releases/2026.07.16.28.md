### Incremental runtime row updates
- Performance: Docker, VM, and Dashboard live refreshes now diff keyed runtime entities and patch only rows whose state, autostart, update, manager, identity, or folder-label data changed.
- UI/UX: In-place updates preserve expanded folders, focus, menus, previews, current ordering, scroll position, and existing host row elements instead of rebuilding the full runtime list.
- Performance: VM start, stop, pause, and resume actions now apply an immediate incremental refresh plus one delayed confirmation pass.
- Safety: Entity additions or removals and folder or preference revision changes still use the full Unraid list rebuild so membership and ordering cannot become stale.
- Diagnostics: Docker, VM, and Dashboard runtime state now records incremental versus structural reconciliation counts for troubleshooting.
- Test: Adds runtime diff coverage for changed, unchanged, added, and removed entities plus contracts for all three incremental render paths.
