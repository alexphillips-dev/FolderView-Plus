### Live Docker action-menu state
- Fix: Container menus now immediately switch between Start, Stop, Pause, and Resume after lifecycle actions without requiring a page refresh.
- Fix: Prevents stale Start actions from being offered for containers that are already running, eliminating the resulting Docker "already running" error.
- Reliability: Native Unraid context menus now resolve lifecycle state from FolderView Plus's canonical runtime cache instead of the original row's immutable inline arguments.
- UI/UX: Already-initialized folder preview popups refresh their status icon and available actions as soon as incremental runtime reconciliation settles.
- Test: Adds stopped-to-started-to-stopped regression coverage for native context menus and live preview popup refreshes.
