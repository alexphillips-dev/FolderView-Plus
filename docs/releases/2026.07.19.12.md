# FolderView Plus 2026.07.19.12
- Reliability: Route durable folder maps, preferences, configuration metadata, diagnostics history, backups, rollback snapshots, templates, theme state, request tokens, Unraid autostart state, and custom icon files through one atomic storage service.
- Safety: Write to a sibling temporary file, flush file contents, atomically replace the target, preserve file permissions, clean up failed temp files, and attempt a parent-directory flush where the platform supports it.
- Recovery: Maintain atomic `.lastgood` JSON mirrors, preserve a successful primary commit when its recovery mirror fails, and refuse to restore corrupt last-good data.
- Diagnostics: Carry one trace and transaction ID across browser requests, API responses and errors, backups, rollback snapshots, configuration revisions, activity history, storage status, and sanitized support bundles.
- Fix: Store uploaded and mirrored custom icon bytes through the same durable writer instead of directly moving or copying data into persistent plugin storage.
- Regression guard: Classify every remaining direct PHP file write and fail validation if a new unclassified write bypasses the durable storage boundary.
- Test: Add failure injection for parent creation, read-only flash storage, temp creation and writes, interrupted writes, full disks, file flushes, atomic renames, directory flushes, last-good failures, and corrupt recovery copies.
- Docs: Document which state is durable, which logs and caches remain intentionally disposable, the commit guarantees, and the storage failure-testing contract.
