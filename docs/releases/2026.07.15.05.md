### Instant preference saving
- Feature: Added a shared optimistic preference-save coordinator so Docker, VM, Dashboard, Settings, privacy, folder order, pin, expansion, and auto-rule changes update the interface immediately.
- Performance: Coalesced rapid edits into a single patch per preference type and serialized writes to avoid redundant requests and out-of-order saves.
- UI/UX: Added clear Saved, Saving, and Sync pending status feedback in Settings without blocking normal interaction.

### Reliability and recovery
- Fix: Persisted unsent preference changes in a local outbox so refreshes, navigation, brief network outages, and browser restarts no longer discard pending edits.
- Fix: Added revision-aware conflict recovery that refreshes the server state, reapplies the pending patch, and retries without rolling back the visible interface.
- Fix: Synchronized saved preference changes across browser tabs while preventing duplicate server writes.
- Fix: Restricted automatic retries to transient request failures and retained permanent failures for an intentional later retry.
- Fix: Recursively merged nested preference patches on the server while continuing to replace ordered arrays atomically.
- Fix: Coalesced rapid preference backup checkpoints so a burst of saves retains one useful pre-change snapshot without excessive filesystem work.

### Diagnostics and quality
- Diagnostics: Added aggregate preference-save health, queue, retry, conflict, and latency details to sanitized support bundles without exporting preference values.
- Quality: Added regression coverage for optimistic updates, request coalescing, serialized writes, durable reload recovery, conflict rebasing, cross-tab convergence, nested server merges, backup coalescing, retry classification, request status propagation, and sanitized telemetry.
