- UI/UX: Moving and reordering folders in Basic Settings updates the row immediately without scrolling back to it after the save finishes.
- Fix: Routine folder moves, reorders, preference changes, and pin changes no longer create a backup snapshot for each action. Folder move and reorder Undo/Redo now use the current browser session's change history.
- Reliability: New setups enable scheduled backups every hour by default. The interval can be changed or disabled in Advanced > Recovery; existing saved schedules keep their settings. Scheduled backups run outside Settings folder reads.
- Compatibility: Explicit safety backups for destructive changes, imports, bulk operations, and restores remain available. Hard-refresh the Unraid webGUI after updating to load the revised Settings assets.
