- Feature: Docker and VMs now include an expanding Quick finder to the left of the native Basic/Advanced view controls. Search folders and members by name or nested folder path, narrow results by type, and reveal a match without manually opening each folder.
- Feature: Search results offer folder focus and editing, available Docker WebUI/log/console shortcuts, and VM logs and native VM actions. Revealing an item clears temporary focus and Docker filters, expands its containing path, and highlights its row.
- Accessibility: Quick finder supports keyboard navigation, Escape dismissal, mobile dropdowns, light and dark themes, right-to-left layouts, and reduced-motion preferences. Privacy name masking also covers search results and the query; searches are not saved or included in diagnostics.
- Reliability: Search results refresh with folder rendering, validate item availability before acting, limit visible matches for large inventories, and remove handlers during page teardown.
- Docs: Added Quick finder usage and action availability to the user guide. After installing, confirm the new version and hard-refresh the Unraid webGUI. Existing folder assignments and preferences are preserved.
