## FolderView Plus 2026.08.10.07

This development build fixes a Settings regression that could leave an inactive import progress dialog visible immediately after page load.

### Settings import progress

- Fix: Keep the import progress overlay and dialog hidden until an import or related operation explicitly opens them.
- Accessibility: Synchronize the dialog's semantic `hidden` state with `aria-hidden` throughout its open and close lifecycle.
- Security: Preserve CSP compatibility without restoring inline display styles.
- Quality: Mirror the production CSS cascade in the browser fixture and verify the complete hidden, open, and closed lifecycle.
