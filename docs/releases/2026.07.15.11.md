### Smarter Settings search
- Feature: Added setting-level word-token search with privacy-safe indexing of labels, descriptions, aliases, and control metadata.
- UI/UX: Added live result counts, highlighted matches, Enter-to-jump navigation, a clear button, Escape-to-reset behavior, and a dedicated no-results panel.
- UI/UX: Replaced the Advanced search checkbox with a compact Current tab/All advanced scope selector and hid it in Basic mode.
- Performance: Added a cached search index and short input debounce so large Settings pages remain responsive while typing.
- Accessibility: Added native search semantics, accessible scope and clear controls, and polite live-result announcements.
- Quality: Preserved independent Basic and per-tab Advanced queries while excluding folder names, runtime tables, dynamic lists, outputs, and entered values from the index.
- Test: Added focused regressions for search structure, matching, privacy exclusions, persistence, keyboard behavior, responsive styling, and scope handling.
