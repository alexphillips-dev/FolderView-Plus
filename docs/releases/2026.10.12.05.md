- Fix: Custom icons cannot be renamed while referenced by Docker or VM folders, saved folder defaults, custom folder-group templates, or the current editor selection. The refusal explains how to remove or replace those references first.
- Fix: Unused icon renames now preserve icon files, metadata, and public copies when an update fails. Systems using copied public icons no longer restore the old filename during a successful rename.
- Compatibility: Unused icon renames and same-name requests remain supported. Existing folder preferences and configuration formats are unchanged; no migration is required.
