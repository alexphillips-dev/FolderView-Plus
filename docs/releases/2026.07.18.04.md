## FolderView Plus 2026.07.18.04

This stable release rolls up all development work since `v2026.07.14.19`.

### Features and workflows

- Feature: Added stable Docker and VM member identities so uniquely identified renamed members keep folder membership, preview visibility, and custom-action targets without guessing when duplicate Docker images are ambiguous.
- Added per-member **Show in preview** controls, an all-hidden preview state, preview overflow choices for configured limits, full expansion or horizontal scrolling, and optional colored preview-row separators.
- Added an Embossed Dashboard layout, authoritative per-folder status-color locking, and a separate Docker folder-name highlight when any member has an available update.
- Added a responsive Docker action toolbar with Add Folder, Expand All, Collapse All, Manage Folders, live Unassigned/Updates/Empty/Health Issues filters, View controls, and troubleshooting Tools.
- Added hierarchy-aware toolbar counts and temporary filters that never rewrite saved folder order, plus accessible menu focus, keyboard navigation, outside-click dismissal, and responsive above/below positioning.
- Added a compact Docker privacy quick-control menu for names/icons, LAN IPs, ports, volume paths, image registries, public IPs, interfaces, and external URLs.
- Rebuilt Docker and VM configuration import as a compact decision-first flow with plain-language Merge safely, Add new only, and Replace exactly modes; live change totals; progressive disclosure; automatic backup; dry-run support; per-operation selection; and explicit destructive/untrusted confirmation.
- Allowed Setup Assistant migration flows to skip the optional Import step when no Docker or VM export is selected while continuing to validate enabled, legacy, and malformed import plans correctly.
- Added one atomic server transaction for configuration imports and bulk deletes, replacing per-folder requests and repeated configuration rewrites.
- Extended atomic batching to starter templates, Setup Assistant folder creation and membership, rule-preview assignments, shared bulk assignment, and nested-tree repair.
- Added one coherent, versioned runtime snapshot per Docker/VM type so folders, preferences, saved order, metadata revisions, and runtime entities come from the same configuration generation.
- Added conditional runtime snapshot tokens so unchanged polling can omit folder and runtime payloads, while retaining the legacy read endpoints as compatibility fallbacks.
- Standardized every FolderView Plus-owned browser request through one shared client with request tokens, trace IDs, timeouts, encoding, parsing, abort handling, upload progress, keepalive writes, normalized errors, controlled GET retries, and no ambiguous mutation replay.
- Added keyed incremental Docker, VM, and Dashboard row reconciliation so ordinary state changes update only affected rows while structural changes still use the safe full rebuild path.
- Moved the 1,982-file third-party icon library into independently versioned icon asset pack `1.0.0`, with persistent cache reuse, checksum verification, staged extraction, atomic activation, runtime linking, and support-bundle identity.

### Configuration safety and saving

- Added versioned metadata sidecars for Docker/VM folders and preferences while preserving existing configuration-file compatibility.
- Added revision-aware saves so stale editors or browser tabs cannot silently overwrite newer folder or preference changes.
- Serialized configuration mutations behind a shared lock and synchronized preference revisions when manual order reconciliation occurs during a save.
- Added automatic detection and reconciliation for configuration files changed outside FolderView Plus.
- Added metadata integrity, revision history, and fingerprints to Diagnostics and sanitized support bundles, plus a Suggested Fix that safely rebuilds configuration metadata.
- Made custom-icon metadata atomic and recoverable through a last-good copy.
- Added a shared optimistic preference coordinator across Docker, VM, Dashboard, Settings, privacy, folder order, pinning, expansion, and auto-rules so visible changes apply immediately.
- Coalesced rapid preference edits into one nested patch per type, serialized writes, and replaced ordered arrays atomically while recursively merging preference objects.
- Added a durable local outbox so refreshes, navigation, browser restarts, and brief network outages do not discard unsent preference changes.
- Added revision-conflict rebasing, transient retry classification, intentional retention of permanent failures, cross-tab convergence, and coalesced backup checkpoints.
- Added sanitized preference-save queue, retry, conflict, outbox, and latency telemetry without exporting preference values.

### Privacy and security

- Fixed Docker privacy mode persistence across refreshes, navigation, and browser tabs with durable browser state and background server reconciliation.
- Fixed Settings privacy checkboxes so unchecked values persist as leaf-level updates without stale Dashboard fields restoring them.
- Reapplied Docker, VM, and Dashboard privacy classes whenever synchronized preferences change, including another tab and restored outbox replay.
- Masked icons and names inside collapsed folder previews as well as expanded native rows.
- Added granular native Docker masking for Container IP, Container Port, and combined LAN IP/port values.
- Replaced the ineffective Container IP setting with **Mask LAN IPs**, removed the redundant local-IP control, and made LAN IP and port masking independent.
- Preserved native LAN mapping text while independently handling IPv4, bracketed IPv6, multiple mappings, and refreshed host rows.
- Expanded reversible masking to Docker volume paths, image registries, public IPs, interfaces, external URLs, VM disk paths, and VM MAC addresses with private-address-aware classification.
- Applied privacy-menu changes optimistically through the conflict-safe preference coordinator and added dialog semantics, expanded-state reporting, Escape/outside-click dismissal, and focus restoration.

### Docker, VM, and Dashboard reliability

- Stopped Docker start, stop, pause, resume, and restart actions from exposing the ungrouped native table or invoking destructive global `loadlist()` rebuilds.
- Prevented lifecycle preference-revision churn from escalating into grouped-table rebuild loops while retaining structural rebuilds outside protected lifecycle reconciliation.
- Added bounded lightweight lifecycle confirmation passes so delayed Docker state changes settle without replacing the folder DOM.
- Fixed lifecycle status icons that remained spinning after actions settled across expanded rows, hidden members, and compact folder previews.
- Made native container menus and initialized preview popups switch immediately between Start, Stop, Pause, and Resume using the canonical runtime cache, eliminating stale Start actions and “already running” errors.
- Preserved expanded folders, focus, menus, previews, ordering, scroll position, and existing host rows during incremental lifecycle updates.
- Reused one primed runtime snapshot during Docker startup, deferred advanced detail hydration until after the lightweight folder view was visible, and stabilized Application-column sizing behind a generation-safe measurement gate.
- Replaced per-folder frame yields with elapsed-work budgeting and ultimately matched FolderView3’s native-first, uninterrupted folder conversion so Unraid rows remain visible until every folder commits synchronously.
- Removed the temporary cloned snapshot and hidden-table staging approaches used during startup investigation, preventing blank tables and cascading chevron paints.
- Stopped Update All and folder-update callbacks from recursively rebuilding the Docker list, replacing the former 120-second redraw cycle with finite coalesced incremental refreshes.
- Fixed Docker View switching so native rows are restored before applying a selected FolderView mode, preventing duplicate folder rows after repeated transitions.
- Removed the retired Tree Explorer and Orbit views, assets, preferences, translations, privacy paths, and runtime modules; legacy saved values now normalize safely to FolderView.
- Restored Host list as the native Unraid container table with defensive extraction, duplicate removal, host-order restoration, and fallback placement for containers missing from saved order.
- Tightened the Docker header/control spacing around Basic View and Privacy without changing native table or folder-row spacing.
- Fixed toolbar Reset View, Empty-only filter recovery, full-width toolbar placement, viewport menu positioning, and hidden-empty/filter conflicts.
- Added Docker, VM, and Dashboard reconciliation counters and lifecycle/request traces to sanitized troubleshooting telemetry.

- Added live result counts, highlighted matches, Enter-to-jump, compact clear, Escape reset, accessible search semantics, polite announcements, and a dedicated no-results state.
- Added Current tab/All advanced search scope while preserving independent Basic and per-tab Advanced queries and excluding folder names, runtime tables, outputs, entered values, and dynamic lists.
- Aligned Search, Basic, Advanced, and Wizard controls; fixed search width clipping; added responsive mobile layout; and rebuilt the clear control as a compact theme-safe icon button.
- Aligned and optically balanced the Wizard button and applied the theme-aware information blue to its icon and label.
- Removed the Saved/Saving badge from the Settings topbar while preserving background preference synchronization and diagnostics.
- Replaced generic update summaries with the exact heading and changes recorded for the installed version and fixed parsing so descriptive section headings remain inside the correct release block.
- Fixed semicolon-separated localization bindings so Settings placeholders, ARIA labels, titles, and button text resolve independently instead of displaying concatenated keys.
- Updated the modern folder-editor live preview immediately when Show in preview changes, tracked visibility-only dirty state, cleared stale hidden state when excluding members, and displayed a clear all-hidden message.
- Made the Docker privacy menu compact and icon-width with no idle border/fill, raised its text to `1.2rem`, and increased its responsive height so normal desktop layouts avoid a scrollbar.

### Import UI/UX and performance

- Reduced the import popup to one compact responsive column with consistent module widths, spacing, footer alignment, and a bounded vertical scroller.
- Moved changed folders, operation selection, safety options, file metadata, technical summaries, and dry-run controls into progressive-disclosure sections while retaining all import capabilities.
- Removed redundant preset controls from the popup, retained server-side preset initialization compatibility, and renamed the remaining distinct controls to Safety options.

- Removed fixed completion delays and reduced large import/delete operations to one lock, one normalized write, one metadata commit, and one final order reconciliation with rollback on post-write failure.

- Replaced single-maximum performance warnings with a 15-minute evidence window that ignores cold loads for alerting, requires repeated warm overruns, and still flags an extreme warm overrun immediately.
- Grouped nested Settings timings into one advisory, added freshness metadata and expandable technical details, and added Retest performance for a new warm measurement.
- Treated an unavailable native Docker Organizer API as informational, reserved warnings for detected organizer sync failures, and added a forced **Check again** capability probe.
- Added structured, sanitized organizer capability/failure stages and separated base GraphQL availability from organizer-schema availability.
- Added a Localization readiness card covering active resolution, legacy/namespace coverage, catalog currency, missing keys, load failures, and the remaining extraction backlog.
- Removed the redundant Simple folder health snapshot and its renderer, filters, actions, styles, and section metadata while retaining Basic-table health calculations.
- Placed Performance Budgets, Native Docker Organizer, and Localization on one balanced desktop row with responsive wrapping.
- Increased Suggested fixes, Core health, Performance advisories, Optional integrations, and Share with support headings to `1.3rem` and gave Share with support a theme-safe blue accent.
- Added bounded sanitized plugin-request history with endpoint paths, outcomes, status codes, durations, attempts, and trace IDs to support-bundle UI telemetry.
