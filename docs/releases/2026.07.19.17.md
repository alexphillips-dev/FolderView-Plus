# FolderView Plus 2026.07.19.17

This stable release brings together every change made on `dev` since stable `2026.07.19.02`, including the performance-profile overhaul, the new folder action sheet, full localization coverage, shared runtime and UI architecture, storage and API hardening, expanded documentation, and clearer installation reporting.

## Features

- Feature: Replace the single Performance mode switch with Standard, Adaptive (recommended), and Maximum performance profiles; existing enabled Performance mode preferences migrate automatically to Adaptive.
- Feature: Add an effective-policy summary for Docker and VM settings showing why optimization is active, the actual refresh interval, expansion-restore limit, and preview strategy.
- Feature: Consolidate Move to root, Move under, and Tree move into one guided Move folder flow supporting root, inside, before, and after destinations.
- Feature: Make branch actions context-aware so the action sheet only presents the applicable Expand or Collapse and Pin or Unpin branch action.
- Feature: Consolidate folder and branch exports into one context-aware export action while retaining guided import into the selected folder.
- Feature: Add a shared, theme-aware UI component layer for Settings, Docker, VM, Dashboard, and the modern folder editor.
- Feature: Provide reusable modal and action-sheet, confirmation, alert, button, icon button, disclosure, badge, form field, error, dropdown, multiselect, toast, progress, empty-state, and loading-state APIs.
- Feature: Translate legacy page text, placeholders, titles, accessibility labels, dynamic UI, and parameterized live-state messages through the generated localization surface.
- Feature: Expand the release-note taxonomy with dedicated Reliability, Privacy, Accessibility, Localization, and Diagnostics tags while preserving every existing category.

## UI/UX and accessibility

- UI/UX: Replace the oversized folder More popup with a compact, single-column action sheet shared by Docker and VM folders.
- UI/UX: Add a concise folder header, live member-state chips, progressive folder details, and a separated delete action without duplicating the table's Edit and Pin controls.
- UI/UX: Add a responsive, safe-area-aware mobile bottom sheet with contained scrolling and theme-token styling that avoids orange-filled action buttons.
- UI/UX: Standardize neutral button hover and focus behavior, responsive modal sizing, contained scrolling, mobile safe-area handling, status tones, compact badges, and theme-token surfaces.
- UI/UX: Replace the generic install footer with a compact report identifying installation, upgrade, reinstall, or downgrade and summarizing version, core package, icon pack, persistent data, scheduler, elapsed time, and next step.
- UI/UX: Show previous-to-current versions during upgrades, whether the icon pack was activated or reused, preserved backup and custom-content counts, and compatibility guidance after downgrades.
- Accessibility: Give the folder action sheet full dialog semantics, initial focus, keyboard focus trapping, Escape and backdrop dismissal, focus restoration, and descriptive labels.
- Accessibility: Give shared managed dialogs consistent ARIA semantics, nested-dialog ordering, live announcements, body scroll locking, and trigger focus restoration.

## Performance

- Performance: Make Adaptive respond to real library size and measured render cost, with hysteresis that prevents repeated switching near a threshold.
- Performance: Give Maximum performance deterministic limits for refresh cadence, restored expanded folders, motion, and offscreen preview work.
- Performance: Hydrate large offscreen Docker and VM previews as they approach the viewport without changing any folder's saved preview or action configuration.
- Performance: Schedule Dashboard Docker and VM refreshes independently so one runtime cannot delay or duplicate the other runtime's refresh cycle.
- Performance: Index exact and parameterized localization phrases once, batch MutationObserver updates, and collapse nested mutation roots before translating dynamic UI.
- Performance: Replace unbounded localization microtask flushes with one animation-frame batch and collapse very large mutation bursts into one bounded document scan.
- Performance: Add required browser runtime budgets for small 25-folder/50-member, normal 100-folder/500-member, and extreme 250-folder/2,000-member configurations.
- Performance: Measure time until native rows are visible, one-shot folder grouping, Settings bootstrap, modern editor opening, start/stop reconciliation, Update-All reconciliation, DOM size, observer volume, retained heap, and bootstrap network requests.
- Performance: Use warm-up and fresh-page samples with stable medians, absolute ceilings, tracked baselines, percentage tolerances, and metric-specific noise floors—including a first-paint scheduling allowance—so hosted-runner contention does not create false release failures while absolute limits remain enforced.

## Fixes

- Fix: Preserve saved expanded-folder preferences when the active performance profile limits how many folders are restored during the current page load.
- Fix: Flush deferred previews before full or incremental reconciliation so container and VM lifecycle changes cannot leave stale preview content.
- Fix: Correct the Setup Assistant Power preset so its requested refresh interval no longer conflicts with the runtime minimum.
- Fix: Harden support-bundle enum sanitization for set-backed and list-backed allowlists.
- Fix: Stop the localization observer from retranslating its own Settings mutations, which could leave Settings as one long uninitialized page, keep the browser spinner active, and eventually crash the tab.
- Fix: Make text, HTML, and attribute translation idempotent and track translated text-node output so observer callbacks settle while later application changes remain translatable.
- Fix: Store uploaded and mirrored custom icon bytes through the durable storage service instead of moving or copying them directly into persistent storage.
- Fix: Correct Settings persistence documentation after removal of the visible saved indicator and replace retired quick-actions-modal terminology with folder action sheet.

## Docker, VM, and runtime architecture

- Refactor: Add one shared, immutable host-adapter contract for Docker and VM table discovery, row classification, structure validation, row observation, and Unraid lifecycle integration.
- Reliability: Make Docker and VM host hooks idempotent so repeated initialization updates the active handler without stacking wrappers while preserving original context, arguments, return values, and compatibility aliases.
- Reliability: Route Docker list and view refreshes, update dialogs, lifecycle actions, container context menus, action-bar discovery, and VM load and detail-row handling through the common host boundary.
- Diagnostics: Add Docker and VM host-adapter snapshots covering host structure, native and folder row counts, observer ownership, hook availability, invocation counts, and timestamps.
- Regression guard: Prevent either runtime from reintroducing independent selector preflights, direct lifecycle wrappers, duplicate observer ownership, or retired wrapper markers.
- Refactor: Route Settings toast and error output, rollback confirmation, Diagnostics actions, import disclosures and badges, folder action controls, and Docker action-bar controls through shared UI primitives and delegated actions.
- Compatibility: Retain a guarded legacy SweetAlert fallback while shared primitives are adopted incrementally.

## Localization

- Localization: Complete coverage for the remaining 1,564 initial and runtime-written legacy messages, increasing every shipped locale from 373 to 1,937 translated catalog messages.
- Localization: Ship the generated surface in Czech, German, Spanish, French, Italian, Japanese, Korean, Dutch, Polish, Brazilian Portuguese, European Portuguese, Romanian, Russian, Swedish, Turkish, Ukrainian, and Simplified Chinese.
- Localization: Preserve `$1`, `$2`, and other runtime parameters so names, counts, progress values, and import results cannot be lost or treated as currency.
- Localization: Load the generated `legacy-surface` namespace on every localized plugin page while retaining English fallback if a catalog asset cannot load.
- Localization: Add and translate seven shared modal, notification, loading, and confirmation labels across all 18 shipped catalogs, increasing each catalog to 1,944 messages.
- Diagnostics: Replace the prior 1,588-candidate localization backlog with a zero-uncovered contract and expose the 1,564 automatically bound messages in runtime and support diagnostics.
- Quality: Add a deterministic localization builder with stable content-addressed keys, existing-translation reuse, request timeouts, progress checkpoints, and placeholder-integrity enforcement.
- Regression guard: Fail validation whenever a detected user-facing phrase lacks a current entry in any shipped locale rather than permitting a hard-coded-string backlog.

## Reliability, storage, and recovery

- Reliability: Route durable folder maps, preferences, configuration metadata, diagnostics history, backups, rollback snapshots, templates, theme state, request tokens, Unraid autostart state, and custom icons through one atomic storage service.
- Reliability: Write through a sibling temporary file, flush contents, atomically replace the target, preserve permissions, clean failed temporary files, and attempt a parent-directory flush where supported.
- Reliability: Maintain atomic `.lastgood` JSON mirrors, preserve a successful primary commit if its recovery mirror fails, and reject corrupt recovery data.
- Reliability: Carry one trace and transaction ID across browser requests, API responses and errors, backups, rollback snapshots, configuration revisions, activity history, storage status, and sanitized support bundles.
- Reliability: Record install context before replacement and write the installed version only after icon-pack and scheduler setup complete.
- Reliability: Distinguish successful scheduler registration from a cron-daemon restart warning instead of reporting the entire installation as failed.
- Reliability: Add stage-aware installation failures with the failed stage, exit code, icon-pack verification details, and previous installed version without emitting a false success report.
- Regression guard: Classify every remaining direct PHP file write and fail validation if durable data bypasses the atomic storage boundary.
