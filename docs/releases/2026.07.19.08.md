# FolderView Plus 2026.07.19.08

- Fix: Stop the localization observer from repeatedly translating its own Settings-page text mutations, which left Settings as one uninitialized long page, kept the browser tab spinner active, and could eventually crash the tab.
- Reliability: Make explicit text, HTML, and attribute translation idempotent so the runtime only writes to the DOM when the localized value actually differs.
- Reliability: Track automatically translated text-node output so observer callbacks settle immediately while still allowing later application-driven text changes to be translated.
- Performance: Replace unbounded microtask translation flushes with one animation-frame batch and collapse very large mutation bursts into one bounded document scan, allowing Settings bootstrap timers and rendering to continue normally.
- Quality: Remove the generic jQuery DOM translation fallback from observer-driven paths and retain the explicit, generated-surface translator as the single DOM mutation owner.
- Test: Add a browser stress regression that inserts more than 300 Settings-like localized nodes, verifies initial and dynamic translation, proves a timer heartbeat is not starved, and confirms translation counts stop changing after the UI settles.
