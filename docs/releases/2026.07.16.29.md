### Stable Docker lifecycle refreshes
- Fix: Starting, stopping, pausing, resuming, or restarting a container no longer exposes Unraid's ungrouped container table while FolderView reloads.
- Performance: Native Unraid and FolderView lifecycle actions now use keyed in-place runtime reconciliation instead of the destructive global `loadlist` callback.
- Reliability: Lifecycle transitions receive three lightweight refresh attempts across two seconds so delayed Docker state changes settle without rebuilding the grouped DOM.
- UI/UX: Expanded folders, menus, focus, scroll position, previews, ordering, and existing rows remain mounted during container state changes.
- Safety: Real folder or preference revision changes still retain the full rebuild path, while transient empty or structurally incomplete runtime responses preserve the current grouped view.
- Diagnostics: Lifecycle callback interception and incremental refresh results are recorded in Docker troubleshooting telemetry.
- Test: Adds regression coverage proving lifecycle callbacks cannot invoke `loadlist` while unrelated structural callbacks remain unchanged.
