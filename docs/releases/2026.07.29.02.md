## FolderView Plus 2026.07.29.02

### Export download diagnostics

- Diagnostics: Record a bounded, privacy-safe lifecycle for Docker, VM, and plugin configuration downloads so support bundles can distinguish payload generation, browser dispatch, synchronous failures, and user-confirmed missing downloads.
- Privacy: Store only fixed-schema metadata such as export type, surface, size bucket, browser capabilities, and lifecycle outcome; export names, configuration content, container names, paths, addresses, and identifiers are never persisted in download diagnostics.
- Diagnostics: Include recent download attempts and aggregate outcomes in sanitized support bundles without claiming a browser save completed when the browser does not provide a completion signal.

### Inline recovery

- UI/UX: Show export-download status next to the export controls with clear “Download didn’t start” and “Retry download” actions instead of popup notifications.
- Reliability: Keep a short-lived in-memory copy of the latest export payload so a direct user click can retry the browser download with fresh user activation.
- Accessibility: Provide theme-aware, responsive, keyboard-accessible status and recovery controls with localized text across all 18 supported locales.

### Validation and packaging

- Quality: Add unit and browser-fixture coverage for privacy boundaries, missing-download reporting, synchronous failures, retry behavior, and support-bundle telemetry.
- Quality: Verify the dedicated download-diagnostics stylesheet is present and byte-identical in built and installed plugin artifacts.
