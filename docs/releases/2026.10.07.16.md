- Feature: Added Quick finder to Docker and VMs, immediately to the left of the Basic/Advanced view controls. Click the search icon or press Ctrl+K (Command+K on macOS) to find folders and members by name or nested folder path. Results appear after typing and are separated into counted, collapsible folder and container/VM sections.
- UX: Search results use configured icons, compact cards, folder paths, and readable status badges, including red Stopped indicators. Folder results provide Focus folder and Edit folder; Docker results use familiar WebUI, console, and logs icons. Available three-dot Actions controls open the existing folder or native member menu. Click a result or use arrow keys and Enter to reveal it.
- Compatibility: Docker and VM search remain separate. Revealing a result expands its containing branch and clears temporary focus and Docker filters; unavailable runtime shortcuts remain disabled. Search supports smartphone layouts, light/dark themes, right-to-left text, reduced motion, and keyboard navigation. The results panel moves above the field when needed and stays within the viewport during scrolling and resizing.
- Fix: Removed excess space beneath Docker search cards in Linux WebKit when native wrappers impose larger minimum heights. Pressing Enter immediately after typing now uses the latest query. Closing, changing, or reopening search cancels delayed reveal, focus, and menu work. Search shortcuts preserve dialog focus and do not interrupt input-method composition. Search mounts with the toolbar and preserves neighboring Privacy controls and native button styling.
- Privacy: Quick finder masks result names, folder paths, and identifying icons when Mask names and icons is enabled, including selected and fallback icons. The search field and typed query remain readable. Queries are temporary, are not saved or included in diagnostics, and should be cleared before sharing a screenshot when they identify private workloads.
- Diagnostics: Added Report issue on GitHub beside Export support bundle in Advanced Settings > Diagnostics, with theme-aware burgundy accents. It opens the GitHub issue forms in a separate tab while leaving Diagnostics available. Review and export a sanitized support bundle before attaching it; the shortcut does not upload diagnostics automatically.
- Reliability: Stable release validation now recognizes Quick finder controls with generated IDs, preventing a false release failure while retaining strict unused-selector checks. Synchronization planning uses only current published main after a successful same-repository release, rejecting stale or untrusted publication events while preserving the guarded release process.
- Docs: Updated Docker/VM search, privacy, troubleshooting, reporting, and upgrade guidance. Confirm the installed version and hard-refresh the webGUI after upgrading. Existing folders, assignments, preferences, and backup schedules are preserved; no configuration reset or migration is required.
