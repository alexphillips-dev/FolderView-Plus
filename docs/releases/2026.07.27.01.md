# FolderView Plus 2026.07.27.01

This dev update removes the visible Docker first-load bounce by stabilizing preview actions and sizing the Application column before folder rows become visible.

## Docker first-frame stability

- Fix: Reserve fixed WebUI, console, and log action slots from the first folder-preview render so delayed WebUI metadata no longer shifts the existing action icons.
- Fix: Reconcile preview actions in place during full Docker metadata hydration instead of removing and rebuilding the complete action group.
- Performance: Expose safe WebUI capability, direct URL, and shell hints in the lightweight Docker state response so compatible preview actions can render without waiting for the full template pass.
- Accessibility: Give the icon-only WebUI, console, and log actions explicit accessible names and tooltips.

## Application column sizing

- Fix: Measure localized folder names and status summaries before committing visible folder rows, then apply the measured width in the same render turn.
- Reliability: Replace the legacy width cache with a schema-versioned, algorithm-versioned, content-signature-aware cache that cannot override a larger current measurement.
- Reliability: Keep the first-frame cache bootstrap bounded and validate the cached schema, algorithm, mode, and width before applying it.
- Maintenance: Move reusable width-cache, localized measurement, and bootstrap selection logic into the shared runtime column-layout module.

## Diagnostics and regression coverage

- Diagnostics: Add privacy-safe Docker layout-stability evidence for hydration timing, width stages, fixed action-slot state, action displacement, and scoped layout-shift observations.
- Maintenance: Move Docker layout telemetry into the diagnostics module with single-owner observer lifecycle handling, and extract Docker template-cache orchestration from the main server library.
- Regression guard: Add a delayed-hydration Chromium fixture that verifies stable action nodes, sub-pixel action displacement, fixed slot widths, and identical first-visible and settled Application-column widths.
- Regression guard: Cover lightweight WebUI metadata, cache signature validation, pre-visible width reconciliation, support-bundle telemetry, and state/full snapshot-token parity.
