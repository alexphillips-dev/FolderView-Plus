- Feature: Add folder/group now opens a unified creation popup in Basic Settings for Docker and VMs. Create a single folder, choose preconfigured folders from the setup wizard's categories and Smart suggestions, or build your own named group with folder names and icons.
- Feature: Save, edit, reuse, and delete custom folder groups. Docker and VM groups are stored separately on the server. Saving a group does not create folders; deleting a saved group leaves existing folders intact. Creating a group skips matching existing folder names.
- UX: Refresh the Basic toolbar with section icons and descriptions, a clearer two-line sort control, a search shortcut hint, and subtle blue Export and green Import treatments. Add folder/group retains its neutral button style, and the six status blocks retain their existing appearance.
- Compatibility: Custom groups contain folder names and icons and create root-level folders using the existing folder creation defaults. Groups do not copy container or VM assignments. Hard-refresh the Unraid webGUI after updating to load the new assets.
