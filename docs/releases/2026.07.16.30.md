### Docker lifecycle rebuild loop fix
- Fix: Container start, stop, pause, resume, and restart reconciliation can no longer call `loadlist`, including when preference revisions change while the action is settling.
- Fix: Eliminates the repeated native-container flash caused when a rebuild saved expanded-folder state and triggered another revision mismatch on the next retry.
- Performance: Lifecycle refreshes now apply the latest runtime state to existing keyed rows while recording configuration revision changes for diagnostics instead of rebuilding the table.
- UI/UX: Folder rows remain continuously mounted throughout lifecycle actions, preserving expansion, focus, menus, ordering, and scroll position.
- Safety: Non-lifecycle refreshes still rebuild when folder or preference revisions change, preserving structural reconciliation outside the protected action window.
- Test: Extends lifecycle regression coverage to prove preference-revision churn cannot be promoted into a grouped-table rebuild.
