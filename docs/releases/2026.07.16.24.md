### Versioned icon asset pack
- Performance: Moves the 1,982-file third-party icon library out of the frequently rebuilt core plugin archive and into an independently versioned `1.0.0` asset pack.
- Performance: Reuses a checksum-marked extracted icon cache during ordinary plugin updates and rebuilds the RAM cache from the persistent pack after reboot.
- Quality: Verifies the immutable pack with manifest-pinned MD5 and SHA-256 checksums, stages extraction, atomically activates the cache, and keeps the existing third-party icon URLs through a runtime symlink.
- Quality: Adds deterministic asset-pack tooling and release guards that reject source drift, checksum mismatches, unsafe entries, or accidental icon-library inclusion in the core archive.
- Feature: Exposes icon-pack version, checksum, URL, readiness, and link state through runtime metadata and sanitized support-bundle build identity.
- Test: Adds executable regressions for archive contents, checksum rejection, real extraction, atomic activation, cached-pack reuse, endpoint health, packaging exclusion, and support metadata.
