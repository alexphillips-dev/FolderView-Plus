### Coherent runtime snapshots
- Performance: Replaces fragmented Docker, VM, and Dashboard bootstrap reads with one versioned runtime snapshot per type while preserving Docker's fast initial state render and deferred detail hydration.
- Fix: Captures folders, preferences, saved order, and metadata revisions under one configuration lock so a render cannot combine values from different save generations.
- Performance: Adds lightweight conditional checks with deterministic snapshot tokens so unchanged live-refresh polls omit folder and runtime payloads.
- Quality: Derives host order from the snapshot's entity generation and normalizes state and full runtime shapes to the same identity before calculating change tokens.
- Compatibility: Keeps the existing read endpoints as per-field fallbacks if the snapshot endpoint is unavailable or returns an unsupported contract.
- Test: Adds endpoint assembly, schema, conditional polling, revision invalidation, client projection, fallback, script-order, packaging, and cross-runtime regression coverage.
