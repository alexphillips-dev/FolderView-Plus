### Faster, stable Docker folder startup
- Performance: The Docker page now reuses one primed coherent runtime snapshot instead of replacing it during the first native `loadlist()` pass or issuing a separate preference request.
- Performance: Full Docker runtime details now begin loading only after the lightweight folder view is visible, keeping advanced metadata off the initial render path.
- UI/UX: The Application column holds its cached width while folders, previews, fonts, and host rows settle, then performs one final measured adjustment instead of visibly resizing several times.
- Performance: Folder rendering now yields according to elapsed browser work rather than pausing after every six folders, reducing unnecessary frame delays on faster systems.
- Reliability: Startup row mutations, font events, preference application, and post-render polish are coalesced behind a generation-safe width stabilization gate.
- Test: Adds focused regression coverage for single-bundle startup, deferred detail hydration, stabilized column sizing, and time-budgeted folder rendering.
