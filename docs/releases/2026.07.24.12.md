# FolderView Plus 2026.07.24.12

This stable release contains every change made on `dev` since stable `2026.07.21.12`. It delivers a complete Filter and view settings redesign, a rebuilt Diagnostics experience and support-bundle workflow, more reliable Docker and VM lifecycle reconciliation, restored Docker privacy masking, preparation for Unraid's evolving Docker interface, and a broad maintainability and regression-testing pass.

## Dashboard and runtime behavior

- Fix: Reconcile Dashboard folders and members after Docker containers transition from stopped to started without requiring a page reload.
- Fix: Keep the Dashboard Started only filter synchronized with live member state, retain the necessary folder hierarchy for running descendants, and hide folders whose members are all stopped.
- Fix: Apply Docker and VM context-menu state from the latest runtime snapshot so lifecycle actions match the entity's actual state.
- Fix: Remove stale spinner, icon, class, and color state after lifecycle actions while preserving canonical host-provided icons.
- Reliability: Use a bounded, state-aware lifecycle refresh window so slower Docker and VM transitions can settle before the UI declares completion.
- Reliability: Cancel stale lifecycle reconciliation when a newer action supersedes it and ignore responses from obsolete page generations.
- Reliability: Fall back to one native host refresh only when incremental Dashboard reconciliation cannot confirm the requested state.
- Feature: Extend VM Dashboard lifecycle parity across start, stop, pause, resume, restart, hibernate, wake, force stop, and console-related state transitions.
- Performance: Reconcile affected Dashboard entities incrementally instead of broadly reloading the host page.
- Privacy: Keep lifecycle telemetry bounded and redact entity names and other sensitive runtime values.
- UI/UX: Increase Activity Center secondary and action-label sizing for better readability.

## Filter and view settings

- UI/UX: Completely redesign Filter and view settings into a compact, card-based workspace with clearer grouping, hierarchy, spacing, controls, and responsive behavior.
- UI/UX: Reduce the section's overall scale and title size while retaining readable labels, descriptions, keyboard focus, and touch targets.
- UI/UX: Reorganize Layout, Folder badges, Runtime, Folder defaults, Dashboard, Health cards, Privacy masking, and Columns into focused modules that explain their effects.
- UI/UX: Improve Expand all, Collapse all, Mobile reorder, Tree scan, and Tree repair controls with consistent state, feedback, and lifecycle handling.
- Feature: Make advanced preview settings persist and apply immediately to active Docker and VM views.
- Fix: Make Health cards visibility, Runtime summary badge, scoring profiles, Updates handling, warning thresholds, critical thresholds, and All stopped mode affect the rendered Dashboard as described.
- Fix: Separate Docker health scoring from VM threshold evaluation so Docker-only conditions cannot distort VM health results.
- Fix: Apply health-profile changes immediately and keep health-derived filter badges synchronized across Settings tabs.
- Fix: Normalize VM thresholds and preserve the VM privacy master switch through save, hydration, navigation, and runtime consumption.
- Fix: Make the All stopped Warning mode produce the intended warning severity instead of being treated as critical or ignored.
- Maintenance: Remove the Compact card layout setting and every persisted, rendered, localized, and runtime compatibility residue associated with it.
- Maintenance: Remove deprecated or inert settings resize paths, retired editor modes, orphaned member-menu branches, obsolete actions, and no-op Compose suggestions.
- Compatibility: Keep settings controls registered in typed metadata, normalize persisted values before use, and retain explicit compatibility handling for supported legacy preferences.

- UI/UX: Add a compact health hero with centered Optional notices, Last checked, Current version, and Core checks metrics plus theme-aware SVG icons and a status progress bar.
- UI/UX: Give Run health check, Retest performance, and Export support bundle distinct but theme-consistent action styling, and remove the redundant Copy issue report action.

- Diagnostics: Add first-class Dashboard visual captures containing viewport, orientation, touch mode, scale, card geometry, grid, overflow, and render-health evidence.
- Diagnostics: Preserve a recent Dashboard capture across navigation to Settings and refresh the support preview immediately when new evidence is available.
- Diagnostics: Add freshness and version-mismatch guidance so support bundles distinguish current visual evidence from stale or incompatible captures.

- Diagnostics: Expand the support-bundle overview with schema version, section coverage, preview time, descriptions, semantic theme-aware icons, and the inclusion state of all seven bundle sections.
