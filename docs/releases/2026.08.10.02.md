## FolderView Plus 2026.08.10.02

This stable release promotes every validated development change since stable `2026.07.24.13`.

### Runtime architecture and maintainability

- Performance: Split Settings startup into a small first-paint foundation and an interaction/idle-deferred workspace while preserving strict dependency order.
- Reliability: Add per-module startup timing, bounded timeouts, failed-module identification, version evidence, and one resumable retry instead of allowing a stalled asset to leave Settings blank.
- Maintenance: Extract focused modules for remote retrieval, Docker layout geometry, container normalization, download diagnostics, support-bundle comparison, and Settings workspace behavior.
- Maintenance: Ratchet architecture budgets for browser globals, inline actions, and the largest JavaScript, CSS, PHP, and page files.
- Quality: Expand JavaScript coverage thresholds, PHPStan analysis, dead-code checks, localization migration budgets, and deterministic browser/runtime performance contracts.
- Docs: Add current architecture, browser-support, Docker compatibility, diagnostics privacy, package storage, security, and release-integrity guidance.

### Docker API compatibility and first-render stability

- Feature: Add operation-level GraphQL capability discovery for Docker queries, mutations, subscriptions, arguments, return types, and deprecation metadata.
- Feature: Add a hybrid legacy/GraphQL provider that prefers schema-confirmed reads and statistics while leaving current Unraid lifecycle actions authoritative.
- Compatibility: Normalize GraphQL, PHP, and DOM container records into one immutable model with stable runtime identity and metadata.
- Reliability: Fall back safely when GraphQL is unavailable or incomplete, reject stale responses, abort owned requests, and dispose subscriptions across navigation.
- Feature: Add targeted single-container reconciliation and aggregate update, orphan, rebuild, and port-conflict health checks.
- Privacy: Keep Docker logs on demand and export only aggregate compatibility and health evidence in sanitized diagnostics.
- Fix: Reserve WebUI, console, and log action slots during the first preview render so later metadata cannot shift existing controls.
- Fix: Reconcile Docker preview actions in place and provide lightweight WebUI capability hints before full template hydration.
- Fix: Measure localized folder/status content before showing rows and use a schema-, algorithm-, and content-aware Application-column width cache.
- Diagnostics: Record privacy-safe first-render timing, width stages, action-slot availability, row motion, and within-row action displacement.
- Maintenance: Track upstream Unraid Docker schema, API releases, source-gate changes, and activation announcements without enabling prerelease organizer mutations.

### Security update sequence

- Security: Require explicit mutation markers, trusted same-origin context, per-install request tokens, and fail-closed token availability for protected POST actions.
- Security: Add target-bound, short-lived, one-time mutation nonces, transaction replay rejection, bounded endpoint rate limits, and standards-based retry guidance.
- Security: Enforce endpoint method, action, content-type, request-size, and parameter contracts through the shared API manifest.
- Security: Restrict folder identifiers, prototype-sensitive keys, external links, WebUI navigation, popup names, image URLs, and localized rich text before browser or server use.
- Security: Preflight icon archives for traversal, links, special files, depth, count, per-file size, total size, and expected top-level content before private staged activation.
- Security: Constrain durable writes to approved roots, reject symbolic-link path components, and use restrictive atomic temporary files.
- Security: Replace direct shell execution with one allowlisted, shell-free `proc_open` boundary using fixed executable candidates, argument arrays, output caps, and timeouts.
- Security: Replace plugin-owned inline event handlers with a delegated declarative bridge that does not use `eval` or the `Function` constructor.
- Security: Reject executable managed-theme content, remote imports, external network URLs, and HTML data URLs before persistence or rendering.
- Security: Generate and verify a deterministic SHA-256 runtime-integrity manifest covering expected files, permissions, and unexpected executable content.
- Security: Record a bounded HMAC hash-chained security audit containing only sanitized action metadata, random trace IDs, status, and timestamps.
- Security: Pin all external GitHub Actions, expand CodeQL coverage, add dependency-review and OpenSSF Scorecard workflows, and maintain high-severity merge protection.
- Privacy: Disable live-system artifact capture by default and prevent CI/release workflows from uploading private Unraid screenshots, URLs, logs, or support data.
- Security: Publish SHA-256 package and icon-pack digests, a complete CycloneDX runtime/workflow SBOM, GitHub OIDC provenance, and SBOM attestations.
- Diagnostics: Surface sanitized runtime-integrity and security-audit health without exposing payloads, names, paths, addresses, tokens, or nonces.
