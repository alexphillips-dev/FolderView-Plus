# FolderView Plus 2026.07.25.05

This dev update prepares FolderView Plus for Unraid's evolving Docker API while preserving the current Docker page and its proven fallback paths.

## Docker API compatibility

- Feature: Add operation-level GraphQL capability discovery for Docker queries, mutations, subscriptions, argument signatures, return types, and deprecation metadata.
- Feature: Introduce a hybrid legacy/GraphQL provider that keeps Unraid's current WebGUI in control while preferring schema-confirmed API reads, container statistics, health metadata, and supported mutations.
- Compatibility: Normalize GraphQL, PHP runtime, and DOM container records into one immutable model with stable identity, ports, mounts, networks, template links, update state, orphan state, autostart metadata, and size fields.
- Reliability: Keep legacy Docker startup non-blocking, fall back safely when GraphQL is unavailable or incomplete, reject stale responses, abort owned work on disposal, and avoid duplicate subscriptions across navigation.

## Runtime data and health

- Feature: Consume Docker statistics subscriptions in Dashboard previews with automatic fallback to Unraid's existing `docker_load` stream.
- Feature: Add targeted single-container reconciliation and aggregate Docker health checks for updates, rebuild readiness, orphaned containers, and container or LAN port conflicts.
- Feature: Add capability-gated update, digest refresh, removal, and autostart mutation adapters while keeping lifecycle buttons on the established Unraid host bridge.
- Privacy: Keep logs bounded and on demand, expose only aggregate compatibility and health evidence to diagnostics, and prevent raw container metadata from entering sanitized support bundles.

## Upstream readiness

- Maintenance: Add a tracked Docker schema signature, latest Unraid API release baseline, and a cross-platform monitor that signals schema drift, new API releases, source-gate activation, release-note announcements, or unavailable upstream evidence.
- Compatibility: Keep Native Docker Organizer integration qualification-only until the upstream page contract is explicitly enabled and validated; no prerelease organizer read or write mutation is activated.
- Docs: Add the Docker API integration contract and update compatibility, runtime architecture, prerelease qualification, and repository-current-state guidance.
- Localization: Add the hybrid-provider and aggregate-health messages across all 18 locale catalogs while preserving the zero-growth legacy localization budget.

## Regression coverage

- Regression guard: Cover capability discovery, partial and permission responses, subscription cleanup, normalized records, hybrid selection, targeted reconciliation, guarded mutations, aggregate health, privacy-safe diagnostics, page include order, and navigation disposal.
- Regression guard: Cover upstream schema changes, newer API releases, unavailable schema evidence, source-gate activation, and release-note activation signals.
