### Standardized plugin requests
- Quality: Routes every FolderView Plus-owned browser request through one shared client while keeping native Unraid Docker, VM, User Scripts, GraphQL, WebSocket, SSE, and logging transports separate.
- Fix: Prevents preference saves, folder mutations, expanded-state writes, and apply-settings operations from being replayed after an ambiguous network failure; reads retain one controlled retry.
- Quality: Standardizes request tokens, trace IDs, encoded query construction, timeouts, JSON parsing, cache controls, abort handling, upload progress, keepalive writes, and normalized HTTP errors.
- Diagnostics: Adds a bounded sanitized request-activity history with endpoint paths, outcomes, status codes, durations, attempts, and trace IDs to support-bundle UI telemetry.
- Compatibility: Preserves icon upload cancellation/progress, unload-safe background synchronization, runtime snapshot polling, and native Unraid action transports during the migration.
- Test: Adds behavior and enforcement coverage that rejects direct plugin-owned Ajax/fetch calls and mutation retry overrides while validating GET retries, URL encoding, diagnostic redaction, and all migrated runtime/editor paths.
