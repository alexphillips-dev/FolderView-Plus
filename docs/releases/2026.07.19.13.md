- Security: Added one versioned endpoint registry that classifies every API and action as read-only or mutating and routes all declared mutations through the shared request guard.
- Reliability: Enforced allowed methods, accepted request content types, request-size limits, required parameters, response contracts, and audit categories before endpoint handlers run.
- Diagnostics: Added API contract and audit-category response headers and included the resolved audit category in server API error records.
- Quality: Replaced incomplete endpoint allowlists in CI, release validation, and install smoke checks with manifest-driven coverage for all 29 public PHP endpoints.
- Test: Added regression coverage for endpoint completeness, mixed read/write actions, mutation guards, invalid methods, unsupported content types, oversized requests, and missing parameters.
- Docs: Documented the endpoint registry workflow and requirements for adding future APIs and actions.
